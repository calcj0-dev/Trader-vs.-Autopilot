# sim：価格モデルと計算の参照実装

- `model.mjs` … 相場の生成（シナリオ・ローソク足）、プレイヤー・積立・一括放置の計算、勝敗判定、称号の判定。04_価格モデルと計算仕様.md と同じ内容で、食い違う場合はこちらが正
- `simulate.mjs` … 戦略別・シナリオ別の勝利／大勝利の割合を試算する
- `result_20000.md` … 20,000相場での試算結果（04章 8章の表の元）
- `titles_check.mjs` / `titles_20000.md` … 称号の出る割合の試算（02章 7章の表の元）

実行（Node.js 18以降）：
```
node simulate.mjs 20000
```
