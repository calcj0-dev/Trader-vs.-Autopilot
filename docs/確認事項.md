## Q1 出来事のニュースが重なる（要決定）
**何が起きるか**
暴落と回復の相場では、A（速報・開始＋2か月）、B（だましの反発・開始＋floor(長さ/2)）、C（悲観・底の1〜3か月前）の月が重なることがある。参照実装で相場番号1〜20,000（暴落と回復は7,054件）を数えた結果：

| 状態 | 件数 | 割合 |
| --- | --- | --- |
| A と B が同じ月 | 1,438 | 20% |
| B と C が同じ月 | 1,913 | 27% |
| A と C が同じ月 | 929 | 13% |
| C（悲観）が A（速報）より前の月 | 485 | 7% |

設計書には「同じ月に2つ来たらどうするか」が書かれていない。また「速報より先に悲観ムード」は話の流れとしておかしい。

**おすすめ**：ニュースの表示だけで調整する（相場と乱数の順番は変えない）。
- 1か月に出す出来事ニュースは1つまで
- A→B→C の順番を守る。重なったり順番が逆になったりしたら、後のものを次の空いている月に送る
- 理由：相場（参照実装との一致）に影響せず、`core/news.ts` だけで済む。ニュースが実際の出来事から少しずれるのは「わざとずらす」という元の方針にも合う

**ほかの案**：重なったら優先度の高い1つだけ出し、ほかは出さない（簡単だが、出ないニュースがある）。

**結論（2026-10-23 オーナー決定）**：おすすめ案で確定。1か月に出す出来事ニュースは1つまで。A→B→C の順を守り、重なった・逆になったときは後のものを次の空いている月に送る。相場と乱数の順番は変えない（`core/news.ts` だけで対応）

## Q2 期間を短くすると相場が作れない（要決定）
**何が起きるか**
シナリオの月の指定（暴落の開始37〜169か月目、だましの戻り61〜151か月目など）は240か月が前提。`gameMonths` を120にすると、参照実装の `generateMarket` は暴落と回復の相場で配列の外を指して止まる（相場番号1〜300のうち76件で失敗。確認済み）。

- T-13 は「期間を120か月にしても最後まで進む」ことを求める
- T-02 は「参照実装と同じ結果」、引き継ぎでは「乱数を使う順番を変えない」とある
- 04章 9章には「期間を変えたらシナリオの月も見直す」とあるが、やり方は書かれていない

**おすすめ**：月の指定を「240か月に対する割合」で持ち、`gameMonths` に合わせて換算する（例：暴落の開始＝`round(36 × gameMonths / 240)`〜`round(168 × gameMonths / 240)`）。
- 240か月のときは参照実装と完全に同じ数値・同じ乱数の順番になる（T-02 を満たす）
- 120か月などでも配列の外を指さない（T-13 を満たす）
- 暴落の長さ（5〜9か月）・戻り（3か月）・調整の長さは月数のまま変えない（短い期間でも暴落らしさを残すため）。そのぶん、短すぎる期間（目安60か月未満）は対象外とする

**ほかの案**：T-13 を「期間を変えるときはシナリオの月も手で直す」に変える（テストは120か月用の設定を別に用意する）。

**結論（2026-10-23 オーナー決定）**：おすすめ案で確定。シナリオの月の指定は240か月に対する割合で持ち、`gameMonths` に合わせて換算する（240か月で参照実装と完全一致）。暴落・戻り・調整の長さは月数のまま。60か月未満は対象外

## Q14 暴落ニュースが短すぎて読めない（要決定・M5 で見つけた）
**何が起きるか**
暴落と回復の相場では、A（速報）・B（反発）・C（悲観）が1か月おき（例：38・39・40か月目）に出る。設計書どおり「出来事のニュースは割り込む」ので、A は約0.3秒で B に、B は約0.3秒で C に替わり、A と B はほぼ読めない（Playwright で確認：4年目3月→4月→5月と替わった）。

**結論（2026-10-26 オーナー決定）**：おすすめ案。出来事のニュースは最低1.5秒（`config.json` の `news.eventMinSec`）出し、次の出来事のニュースはそのあとに送る。v0.8.1 で実装

## Q15 積立に勝つのが簡単すぎる（2026-10-23 オーナー指摘）
**分かったこと（20,000相場の試算）**
- 100万円スタートでは、積立は20年かけて少しずつ買うので、早く買って持つだけで上回りやすい。最初に買って放置で76%、人らしい遊び方（最初の半年で買い、あとは数回売買）で46〜51%が積立に勝つ
- オーナー案「毎月10万円を受け取る。積立は毎月10万円を買う。プレイヤーは『買（手元の現金を全部）』『売（全部）』」では、人らしい遊び方で38%（+5%以上の差で勝つのは27%）、ランダムな売買で27〜30%、「下がったら買う」は52%だが差はほぼ5%未満

**検討して却下した案**
- 売って出た利益に税金20%（積立は NISA で非課税）：積立だけ有利なルールになるため却下
- 手数料・税金を両方にかける：却下（決定事項 #4「手数料・税金なし」のまま）

**結論（2026-10-23 オーナー決定）**：毎月10万円を受け取る形に変える。勝ち負けの段階・一括投資派の代わり・称号・速さ・表示などの細部は、Q15-1 から順に決める

### Q15-1 勝ち負けの段階（2026-10-23 オーナー決定）
最終資産を積立と比べる（通貨の最小単位に丸めてから）。

| 判定 | 条件 | 人らしい遊び方の割合（試算） | ランダム約20回 |
| --- | --- | --- | --- |
| 歴史的勝利 | 積立を **+20%以上** 上回る | 9% | 11% |
| 圧勝 | **+10%以上** 上回る | 10% | 7% |
| 勝利 | 積立を上回る | 19% | 9% |
| 引き分け | 積立と **同じ額のときだけ**（毎月欠かさず買った場合など） | — | — |
| 負け | 積立を下回る | 約62% | 約73% |

- 名前「歴史的勝利」はゲーム内のニュース「とにかく何かが歴史的」と同じ言い方で、くすっと笑える方向。「大勝利」は「圧勝」に改める

- 検討した案：±5%未満を引き分けにする（不採用。積立を超えたら勝利とする）

### Q15-2 一括投資派（2026-10-23 オーナー決定）
- **なくす**。毎月10万円の形では「1回買って放置」は抜け道にならない（受け取ったお金が現金のまま積み上がるので、ほとんど負ける）。毎月欠かさず買えば積立と同じ額で引き分けになる
